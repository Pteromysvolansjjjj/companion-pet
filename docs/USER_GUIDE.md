# 用户使用教程

适用于 **LOL 陪玩数据插件 0.7.1**。你需要 Windows、已配置好模型且能正常聊天的 DeepSeek Harness，以及本机英雄联盟客户端。已验证 DSH 版本：`0.2.1-rc.2`。

## 1. 安装

1. 下载并解压完整项目，放到固定目录，例如 `D:\Apps\lol-companion`。安装后不要随意移动目录。
2. 确认目录中有 `package.json` 和 `dist\LolCompanion-0.7.1.exe`。没有 EXE 的源码包需要先按[技术文档](TECHNICAL.md#development)构建。
3. 打开 DSH 的 **插件 → 添加插件 → 安装第三方插件**，填写项目目录，安装并启用。
4. **完整退出并重开 DSH**，让插件和聊天界面模块一起加载。

如果装过旧版 `lol-widget`，先在插件页停用它，避免工具重名。插件页的文字可能随 DSH 版本略有变化。

## 2. 开始陪玩

打开你平时养角色的原对话，发送：

> 我要打英雄联盟，陪我玩。请调用 lol_watch_start。

看到工具成功启动监听后，打开 LOL 即可；也可以先开游戏。插件沿用这个对话的模型、性格和上下文，无需单独填写 API Key。

游戏显示模式建议选择 **无边框或窗口模式**。独占全屏可能遮住桌宠。

每次重启 DSH 后，重新发送上面这句话。一次只能绑定一个对话；在另一个对话启动会切换绑定。

## 3. 在游戏中打字

- **连续点人物三下**，或右键人物选择聊天，打开下方输入条。
- **Enter** 发送；**Shift + Enter** 换行；**Esc** 收起。中文选词时，Enter 先确认候选词。
- 接收成功后，输入条自动清空收起；输入的话和模型回复留在原工作区 Chat，最终纯文本回复也显示在气泡里。

输入框获得焦点时，游戏暂时收不到键盘操作。发送失败会保留草稿；模型正在回复时，新输入会排入原对话的下一轮。切换绑定会清理旧草稿。

## 4. 调整到你喜欢的节奏

右键桌宠打开 **设置**，先选数据档，再选投递间隔。默认值适合先体验。

| 设置 | 怎么选 |
| --- | --- |
| 主要数据 | 默认。阶段、模式、选人、英雄、等级、KDA、存活状态及新增事件，通常更省用量 |
| 详细数据 | 增加接口提供的血量、金币、装备、计时等字段；不代表能看到全部游戏信息 |
| 投递间隔 | 默认 15 秒；可选 10、5、2、1、0.5 秒或自定义。越短，潜在模型用量越高 |
| 回复长度 | 默认尽量 20 字；属于偏好，可改大或设为不限总字数 |
| 每页停留 | 默认 5 秒；每页另有淡入、淡出各 0.25 秒 |

也可以直接对角色说：

> 请用 lol_tune 改为详细数据，每 5 秒投递一次。

> 请用 lol_tune 取消回复总字数限制，每页停留 8 秒。

自然语言不是固定口令，以模型实际调用工具成功为准。设置按对话保存，重启后保留。

每页最多显示 20 个可见字符，长回复会完整分页。**当前整条回复显示完后，模型才根据最新数据判断下一句**，所以设为 0.5 秒并不保证每半秒开口。没有新变化、模型忙或模型决定沉默时，也不会按秒强行说话。

## 5. 移动、隐藏和停止

| 操作 | 方法 |
| --- | --- |
| 移动 | 拖动人物或气泡 |
| 缩放 | 鼠标放在桌宠上，按住 Ctrl 滚动滚轮 |
| 调大小、字号、吸附 | 右键或托盘菜单 → 设置 |
| 隐藏、恢复位置、退出桌宠 | 右键或托盘菜单 |
| 停止自动陪玩 | 在绑定的原对话说“请调用 lol_watch_stop” |

隐藏或退出桌宠不等同于停止数据监听；要停止自动模型用量，请调用 `lol_watch_stop`。仅说“少说两句”也不等于停止监听。

## 常见问题

**桌面看得到，游戏里看不到？** 先将游戏改为无边框或窗口模式；也可以把桌宠移到副屏。独占全屏不保证覆盖。

**没有反应？** 让原对话调用 `lol_read`，检查 `plugin.version` 是否为 `0.7.1`，再调用 `lol_watch_start`。游戏未开始时 Live 数据不可用是正常情况。工具不存在时，检查插件是否启用并完整重启 DSH；连接问题见[故障排查](TECHNICAL.md#troubleshooting)。

**自动聊天怎么没出现在主对话框？** 自动游戏轮次只在原始记录和轨迹中保留；你手动发的话和对应回复仍在主 Chat。隐藏显示不等于删除上下文。

**角色怎么一开始就懂 LOL？** 模型可能已有游戏知识，原对话也可能有相关上下文。插件没有另加教练人设，也不会训练模型。跨局记忆由原会话或其他记忆工具负责。

**不说话就不计费吗？** 不是。模型判断后返回 `<silent/>` 仍发生了推理。主要数据和较长投递间隔通常更省用量；确实不用时停止监听。

**能看到局内聊天或听到语音吗？** 当前没有聊天 OCR 或 TTS，也不会向游戏聊天发消息。只使用所接入接口实际提供的数据。
